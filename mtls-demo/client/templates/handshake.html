🔑 Key Insight: Why mTLS is Stronger Than Tokens

  • The client private key never leaves the key store. It signs a challenge; the raw key is never transmitted.
  • Stolen cookies/JWTs can be replayed from anywhere. A stolen client certificate is useless without the matching private key.
  • Authentication happens at the TLS layer, before any HTTP request. Unauthenticated clients never reach your application code.
  • In ssl_verify_client on mode, Nginx drops the TCP connection before sending HTTP 401 — attackers cannot probe your API at all.
