❓ What is mTLS?

In standard TLS (HTTPS), only the server authenticates itself to the client using a certificate. The client is anonymous.

In Mutual TLS (mTLS), both parties authenticate each other. The server also requires the client to present a certificate signed by a trusted CA.

  • Used in microservice meshes (Istio, Linkerd), banking APIs, IoT devices, zero-trust networks
  • Prevents unauthorized clients from making any HTTP request — authentication happens at the TLS layer
  • Client certificates cannot be stolen by XSS (unlike cookies/tokens) because they live in the OS key store
