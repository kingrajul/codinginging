🔬 Raw OpenSSL TLS Trace

Run openssl s_client from inside the client container and see the raw TLS state machine output. Compare the handshake with and without a client certificate.

✅ Trace — With Client Certificate

openssl s_client \ -connect mtls-server:443 \ -cert /app/certs/client/client.crt \ -key /app/certs/client/client.key \ -CAfile /app/certs/ca/ca.crt \ -state -brief -verify_return_error
Click Run to execute openssl s_client with client cert…

❌ Trace — Without Client Certificate

openssl s_client \ -connect mtls-server:443 \ -CAfile /app/certs/ca/ca.crt \ -state -brief
Click Run to execute openssl s_client without client cert…

📖 Flag Reference

FlagMeaning
-connect host:portTarget server to connect to
-cert file.crtClient certificate to present during mTLS handshake
-key file.keyPrivate key matching the client certificate
-CAfile ca.crtCA certificate(s) to verify the server's certificate
-statePrint SSL state machine transitions (shows each handshake phase)
-briefPrint a compact summary of the connection (protocol, cipher, cert info)
-verify_return_errorExit with error code if server cert verification fails

🖥️ Try It Yourself with curl

From your Docker host machine (the certs are in the mtls-demo/certs/ directory):

# ✅ With client certificate — should return JSON
curl -v \
  --cert  mtls-demo/certs/client/client.crt \
  --key   mtls-demo/certs/client/client.key \
  --cacert mtls-demo/certs/ca/ca.crt \
  https://localhost:8443/api/cert-info

# ❌ Without client certificate — should fail at TLS handshake
curl -v \
  --cacert mtls-demo/certs/ca/ca.crt \
  https://localhost:8443/api/cert-info

# ❌ Without any cert verification — TLS error (self-signed)
curl -k https://localhost:8443/api/cert-info
