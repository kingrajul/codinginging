🔎 How Nginx Exposes These Values

Nginx makes TLS session data available as variables. This page fetches /api/cert-info which returns:

location /api/cert-info {
    add_header Content-Type 'application/json';
    return 200 '{"verify":"$ssl_client_verify",
                 "subject":"$ssl_client_s_dn",
                 "issuer":"$ssl_client_i_dn",
                 "serial":"$ssl_client_serial",
                 "protocol":"$ssl_protocol",
                 "cipher":"$ssl_cipher"}';
}

These variables are only populated because ssl_verify_client on forces the mTLS handshake. Without it, $ssl_client_verify would always be NONE.

📋 Response Headers (check DevTools)

Every response from this server includes custom headers so you can inspect TLS info in the browser's Network tab:

X-Client-Verify:  SUCCESS
X-Client-Subject: CN=demo-client,OU=Client,O=mTLS Demo,...
X-TLS-Protocol:   TLSv1.3
X-TLS-Cipher:     TLS_AES_256_GCM_SHA384
