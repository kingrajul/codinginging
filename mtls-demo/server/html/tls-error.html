🚫 Client Certificate Required

This server requires mutual TLS (mTLS). Your browser did not present a valid client certificate, so Nginx rejected the handshake.

This is intentional and is the core security benefit of mTLS: the server authenticates you (the client) at the TLS layer, before any HTTP request is processed.

To access this page with a client cert:

curl --cert certs/client/client.crt --key certs/client/client.key --cacert certs/ca/ca.crt https://localhost:8443/

Or import certs/client/client.p12 (password: client123) into your browser's certificate store.
