🔗 Referrer Demo — Target Page

You arrived here from a "sensitive" URL. Open DevTools → Network, find the request for this page, and look at the Request Headers.

What to look for:
In the request that loaded this page, you should see a Referer header containing the full URL from the previous page — including ?token=super-secret-token-123&user=victim@example.com.

In a real scenario this page would be on a different domain (an analytics provider, CDN, ad network) and could log that header value — exposing the token to the third party.
