📖 What is Clickjacking?

Clickjacking (UI Redress Attack) tricks a victim into clicking something on a hidden page by overlaying that page inside a transparent <iframe> on an attacker-controlled site.

Classic targets include: Like buttons, Follow buttons, Transfer funds, Delete account, Allow camera/mic access, OAuth authorization screens.

The victim sees a harmless-looking page; the real click goes to the concealed frame below.

🔴 How the Attack Works — Step by Step

  1. 1Attacker registers a site like win-free-stuff.example.com.
  2. 2The page embeds the target site (e.g. a bank's transfer page) in a full-screen <iframe> with opacity: 0.
  3. 3A tempting button or game element is positioned precisely over the "Confirm Transfer" button in the hidden frame.
  4. 4Victim is lured to the attacker's page and clicks the visible element, unknowingly confirming the transfer on the bank site.
  5. 5The click goes to the bank iframe (victim is already authenticated), the action completes.

Attack code is as simple as:

<!-- attacker's page -->
<style>
  iframe { position:fixed; top:0; left:0; width:100%; height:100%; opacity:0; z-index:2; }
  button { position:fixed; top:320px; left:200px; z-index:1; }
</style>
<iframe src="https://bank.example/transfer?to=attacker&amount=1000"></iframe>
<button>Collect your reward!</button>

✅ The Fix — X-Frame-Options & CSP frame-ancestors

Option 1 — X-Frame-Options (legacy, widely supported):

X-Frame-Options: DENY

Tells every browser: this page must never be loaded in a frame, regardless of the framing origin.

Or allow only same-origin framing (e.g. for embeds within your own site):

X-Frame-Options: SAMEORIGIN

Option 2 — CSP frame-ancestors (modern, more flexible):

Content-Security-Policy: frame-ancestors 'none';

Equivalent to DENY but part of CSP so it overrides X-Frame-Options in modern browsers. Use 'self' instead of 'none' to allow same-origin framing.

You can also whitelist specific origins:

Content-Security-Policy: frame-ancestors 'self' https://trusted-partner.example;

In Nginx — add both for maximum browser coverage:

add_header X-Frame-Options "DENY" always;
add_header Content-Security-Policy "frame-ancestors 'none';" always;
