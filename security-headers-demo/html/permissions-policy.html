📖 What is Permissions-Policy?

Modern browsers expose powerful APIs to web pages — camera, microphone, geolocation, clipboard, payment, USB, Bluetooth, and more. By default these require user permission dialogs.

But without Permissions-Policy, any <iframe> you embed on your page can also request these permissions — including third-party ads, widgets, and analytics iframes you didn't write. If the user has already granted camera access to your site, an embedded iframe on the same page may inherit or piggyback on that permission.

Additionally, if an XSS payload is injected (see CSP page), it can silently try to access these APIs in the background.

🔴 Attack Scenarios

  1. 1Malicious ad iframe: A compromised ad network injects an iframe that activates getUserMedia({video:true}). Without Permissions-Policy restricting camera access to specific origins, the iframe can request the camera.
  2. 2XSS + geolocation: An XSS payload silently calls navigator.geolocation.getCurrentPosition() and beacons the coordinates to an attacker server, revealing the victim's physical location.
  3. 3Payment API abuse: An embedded iframe triggers the Payment Request API, phishing the victim's saved payment details via a spoofed payment sheet.
  4. 4Clipboard hijacking: An iframe reads navigator.clipboard.readText() silently (on sites that have clipboard-read permission), stealing passwords or 2FA codes the user copied.
  5. 5Screen capture: getDisplayMedia() can trigger a screen-share request; if the user accepts thinking it's your app's feature, a third-party iframe captures their screen.

✅ The Fix — Permissions-Policy

Permissions-Policy lets you explicitly allow or block browser features for your page and any iframes it hosts.

Permissions-Policy: camera=(), microphone=(), geolocation=(), payment=(), usb=(), clipboard-read=()

() means nobody — not this page, not any embedded iframe. Use (self) to allow only your own origin.

If you do need a feature on your own page but not in iframes:

Permissions-Policy: camera=(self), microphone=(self), geolocation=(self)

To allow a specific trusted iframe:

Permissions-Policy: camera=(self "https://video.trusted-partner.example")

You can also control iframe permissions with the allow HTML attribute:

<!-- only this iframe can use camera, nothing else -->
<iframe src="https://video.partner.com" allow="camera"></iframe>

<!-- deny everything to this untrusted ad iframe -->
<iframe src="https://ads.network.com" allow=""></iframe>

In Nginx:

add_header Permissions-Policy "camera=(), microphone=(), geolocation=(), payment=(), usb=()" always;
